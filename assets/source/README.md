# Application icon sources

The application icon combines the original vector paths from the Simple Icons
13.0.0 project. The paths are scaled proportionally without changing their geometry.

- OpenAI knot: https://raw.githubusercontent.com/simple-icons/simple-icons/13.0.0/icons/openai.svg
- Telegram circle and airplane: https://raw.githubusercontent.com/simple-icons/simple-icons/13.0.0/icons/telegram.svg
- Source license: https://raw.githubusercontent.com/simple-icons/simple-icons/13.0.0/LICENSE.md
- Project: https://github.com/simple-icons/simple-icons/tree/13.0.0

The source files and CC0 license are retained in this directory. Brand names and
trademarks belong to their respective owners. This is an independent project icon,
not an indication of endorsement by OpenAI or Telegram.

Official reference pages consulted:

- https://openai.com/brand/
- https://telegram.org/tour/screenshots

`../app-icon.svg` is the editable master. Its rounded tile, gradients, positioning,
and badge border are project-specific SVG geometry. The PNG versions were rasterized
from this SVG with sharp; Pillow packaged the PNG into a Windows ICO with 16, 24,
32, 48, 64, 128, and 256 pixel sizes. Transparency is preserved in all exports.

The initial image-generation request was unavailable (HTTP 403, image generation
not enabled). These deliverables use native vector composition; no image model,
paid API, or manually painted raster was used.
